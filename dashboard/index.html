How this dashboard is fed

The agent team keeps one state file in the repo. The Chief of Staff updates it after every run, the sync script merges in aggregate numbers from Aurelium Motion HQ (stage counts, campaigns, activity; never names, phones or emails), and the result is uploaded here as the attached file every source on this page reads.
